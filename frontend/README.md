# Frontend Angular-style base

Esta carpeta contiene la estructura inicial modular para Angular:

- `core/services` para cliente API REST
- `modules/auth` para autenticación
- `modules/customers` para mantenimiento de clientes
- `modules/ecf` para emisión/consulta e-CF

> Nota: Se entrega base de arquitectura y servicios; puede integrarse en un workspace Angular CLI existente.
